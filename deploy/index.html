The payload is an encrypted blob: dumping the file surface reveals nothing. The LZW shell and VERIFY2 layers still run inside it, so the integrity and anti layers execute only after the payload decrypts itself in memory.

How it works

Surface to VM in seven layers

1 · Prometheus VM

Your source is parsed and rewritten through the Prometheus engine (Vmify, Encrypt Strings, Anti Tamper, CFF, Constant Array, Numbers to Expressions).

2 · First blob

The compiled payload is RC4-encrypted with a per-build random key.

3 · LZW shell + VERIFY2

An LZW-compressed shell unpacks the blob and verifies its checksum in memory before executing.

4 · Guard layers

Anti-sandbox, anti-env-log and anti-dump run inside the shell, before your first line executes.

5 · Second blob

The shell is itself RC4-encrypted and LZW-packed into a second blob.

6 · Outer VM

A Prometheus-generated VM harness decrypts, unwraps and runs the whole stack. A seed-validated build ships only after a real Lua 5.1 round-trip.
